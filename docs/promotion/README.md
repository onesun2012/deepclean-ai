## 可直接使用的发布文案

做了一个 Windows 本地小工具 DeepClean，帮助查看 AI 助手、开发缓存和本地模型占用了多少空间。

它按工具展示结果，支持只扫描某个分类或单个工具；会话与历史锁定保护，模型不参与清理。清理前会生成确认清单，执行前再检查文件是否变化。整个工具免费使用，支持作者完全自愿。

目前提供候选版本，迁移仅预览，管理员模式只读。欢迎反馈路径识别、界面使用和扫描中断问题。附图中的数字为演示数据。

源码：https://github.com/onesun2012/deepclean-ai
