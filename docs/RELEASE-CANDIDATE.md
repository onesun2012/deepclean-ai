# 候选项版本说明

**系统要求**：Windows 10 / 11 x64（不支持 Windows 7 / 8）。

本轮围绕“能顺利启动、看清扫描范围、可正常退出”完善桌面使用流程。

2026-09-08 补充：新增独立“直接释放空间”选项，对五类明确目录中至少 7 天未修改的文件开放永久删除；确认框显示目录、筛选后大小和重下载影响。默认普通清理保持回收站方式，具体范围见 `DIRECT-CLEAN.md`。新增 Windows 真实文件句柄的临时目录验收，不清理真实用户数据。

同日（界面 / 产品页补充）：
- 默认界面语言改为英文；工具名补齐 `nameEn`，`/api/state` 下发英文名（如 WeChat、Doubao、App updaters）。
- 停止扫描/清理、退出工具、会话失效提示等改为 i18n。
- 设置页与侧栏增加 Feedback 入口；支持作者渠道支持中英文标签，Afdian 与 GitHub Sponsors 顺序调整。
- 新增 GitHub 产品页 `docs/index.html`（中英文切换、支持作者、FormSubmit 留言反馈），说明见 `docs/SITE.md`。启用 Pages：仓库 Settings → Pages → `/docs`。

同时修复多实例的端口复用问题：Windows 独占监听，遇占用端口跳到下一个。78 项后端/CLI 回归、浏览器流程及源码/EXE 隔离生命周期验收通过，构建摘要核对通过。

- 同用户、同安装路径、同权限模式的实例互斥；重复启动连接已有实例。
- 启动端口由实际服务绑定结果决定，不再使用启动脚本的固定端口探测。
- 设置页和退出脚本通过认证接口退出，不按端口强杀进程；忙碌时要求先停止任务。
- 支持分类扫描、单个工具扫描、CLI 指定分项扫描；未扫描项不可清理。
- 全局清单条目与估算内存预算达到上限时，拒绝本次清理，提示缩小范围重扫。
- 固定构建依赖，生成 EXE 候选项、构建输入清单和 SHA256 摘要。
- 提供带模拟数据标记的截图、短视频和发布文案。

保留限制：迁移仅预览；管理员只读；Shell 路径操作的最终竞态尚未消除；未做真实回收站、真实 SSD/HDD 基准、跨机器逐字节构建复现或代码签名。没有公开发布候选项包。
