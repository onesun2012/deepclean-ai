Product

What it does

  • Scans Cursor, Claude Code, Codex, Hugging Face, Ollama, chat apps, and system junk on Windows
  • Safe defaults: sessions and histories stay locked; clean goes to Recycle Bin when possible
  • Model locations are statistics + preview only until migration is fully hardened
  • All rules live in the open rules/ folder — contributions welcome
  • Requires Windows 10 / 11 x64 (Windows 7 / 8 not supported)
